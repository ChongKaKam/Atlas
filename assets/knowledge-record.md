# Topic

## Overview

填写主要问题、范围和简要认知；篇幅通常不超过全文约 10%。

## Knowledge Map

填写主要 KU 的关系和已存在文档的相对链接，不生成虚构链接。

## Detailed Knowledge

### 重要主题

按内容选择 Definition / Context / Mechanism / Key Details / Conditions & Constraints / Relationships / Evidence / Unknowns 子节。保留参数、版本、中间步骤和例外，不用空 headings 凑结构。

## Conditions / Constraints / Exceptions

仅集中列跨主题限制，局部条件放在对应结论旁。

## Evidence

每条证据注明定位、版本/日期和所支撑的具体结论。

## Facts / Claims / Inferences / Assumptions / Unknowns

说明重要知识的可信度和推导依据；正文已经清晰标注时无需重复。

## Related Topics

添加有实际关系的本地 Markdown 链接及关系说明。
