# Integration Plan

## Scope

填写目标知识库绝对路径、输入路径/来源、已读范围、操作授权。说明是否需要先 review 草案。

## Knowledge Units

| KU / reader question | Context and evidence | Existing candidate | Action | Target and reason |
|---|---|---|---|---|
| 填写具体问题 | 版本/target/来源位置 | 读取过的文件或未发现 | Create/Merge/Extend/Split/Skip/Conflict | 文件和必要段落 |

## Proposed changes

附具体草案或 diff。注明新标签、状态变化、来源归属、文件移动与链接修复。区分范围外暂缓和没有新增价值的 Skip。

## Unresolved decisions

仅列出证据不足的冲突取舍或未授权操作；无则删除这一节。

## Verification

记录目标文件状态、结构与链接检查结果、语义自审范围，以及未读取或无法验证的输入。应用后核对所有 KU 的去向。
